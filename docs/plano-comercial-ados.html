Modelo de Negocio

O usuario baixa o JVOS (desktop app gratis), mas toda a infraestrutura de IA fica conosco. Modelo inspirado no n8n Cloud — self-hosted gratis, managed pago.

Tokens de API (OpenAI, Anthropic, Google), servidores MCP, roteamento multi-agente, atualizacoes automaticas
O usuario configura
Contexto da empresa, preferencias, skills, automacoes, integracoes. Zero fricao tecnica.
Resultado
Paga assinatura fixa mensal e usa. Sem API keys, sem billing em 4 providers, sem entender tokens.

Componentes Tecnicos

1. Token Vault
API keys dos providers com encryption AES-256. Rotacao automatica. Rate limiting por plano. O cliente nunca ve/toca os tokens.
2. LLM Router
Recebe requests, roteia para provider/modelo correto. Fallback automatico. Cache de respostas. Metering por usuario.
3. MCP Proxy
Hospeda MCP servers para usuarios. Isolamento por container. Desktop conecta em servers remotos sem configurar infra.
4. Sync Engine
Sincroniza sessoes entre dispositivos. E2E encryption (chave derivada da senha). Backup diario 30 dias.
5. Marketplace Hub
Skills e workflows da comunidade. Revenue share 70/30. Review antes de publicar. Versionamento.
6. Usage Metering (Asaas)
Conta mensagens, tokens, ferramentas. Dashboard de uso. Alertas em 80%. Cobranca via Asaas (PIX + boleto + NF-e).
