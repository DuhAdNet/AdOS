9. Features Implementadas

🧠 Auto-Memory (Brain Automático)

Após conversas com ≥4 mensagens, gpt-4.1-nano extrai insights e salva no Brain automaticamente.

  • Máximo 3 memórias por sessão
  • Deduplicação >80% match
  • Categorias: user, project, feedback, reference
  • Custo: ~$0.0001 por extração

🔄 Fallback de Modelos

Se o modelo principal falha (timeout, rate limit, 5xx), tenta automaticamente o modelo alternativo configurado no JvosSys.

🔔 Notificações Desktop

Notificações nativas para: automação concluída, sessão background finalizada, agente precisa de input, alerta de uso.

⚠️ Stop Warning

Warning visual ao atingir 10 tool calls: "Limite de ações atingido. Envie outra mensagem para continuar."

🤖 Hierarquia de Bots (JvosSys)

Interface admin para criar bots, definir regras de delegação, testar routing e versionar prompts.

13. Compilação e Deploy

Windows

cd JVOS && npm install && npm run build && npm run package
# → dist/JVOS-Setup.exe

cd JvosSys && npm install && npm run build && npm run package
# → dist/JvosSys-Setup.exe

Linux

cd JVOS && npm install && npm run build && npm run package:linux
# → dist/JVOS.AppImage + dist/ados_1.0.0_amd64.deb

cd JvosSys && npm install && npm run build && npm run package:linux
# → dist/JvosSys.AppImage + dist/jvossys_1.0.0_amd64.deb

Requisitos

  • Node.js 20+
  • npm 10+
  • Git (para git bash no Windows)
  • ~500MB RAM por app rodando
  • Linux: libgtk-3, libnss3, libgbm (para Electron)
